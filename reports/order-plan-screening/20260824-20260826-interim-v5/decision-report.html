지금 말할 수 있는 것

  • TF-IDF와 dense는 전 모집단을 실패 없이 처리해 후보 생성기의 실행 가능성을 확인했다.
  • dense는 의미 기반 전수 점수를 27.67초에 만들었다.
  • Qwen 전수 판정은 73분 11.2초이 걸리고 coverage가 불완전해 현 설정 그대로는 준비되지 않았다.
  • 방법별 Top 후보가 달라 사람 정답 없이 하나를 제거하면 고유 후보를 잃을 수 있다.

아직 말할 수 없는 것

  • 어느 방법의 precision@50이 높은지, 중요한 사업을 덜 놓치는지 알 수 없다.
  • Qwen 실패 건이 순위에서 빠져 현재 Qwen Top 50은 편향될 수 있다.
  • 한 회차·한 번 실행이므로 일별 구성 변화와 성능 분산을 알 수 없다.
  • title-only 외 조건을 추가할 때의 효과는 새 방법 버전으로 검증해야 한다.
중간 엔지니어링 권고: 품질 우승자를 정하지 않고 TF-IDF와 dense를 사람 라벨 후보 생성용으로 함께 유지한다. Qwen은 truncation을 해결한 100% coverage 새 run에서 평가하며 운영 정책을 자동 활성화하지 않는다.

권장 실행 순서

  1. Qwen coverage 복구: 같은 raw·prompt·digest에서 batch 크기, 출력 상한, reasoning을 한 번에 하나만 바꾼 새 run을 만든다. smoke는 별도 ID로 1~2 batch만 실행한다.
  2. 안전한 진행 계측: 본문 없이 batch 번호·상태·latency·token·done reason·오류 코드만 기록한다. 긴 실행은 불변 batch shard와 최종 manifest로 구분하되 자동 fallback하지 않는다.
  3. ColBERT 실행: 같은 title/capability와 997건에서 fixed revision으로 실행한다.
  4. 사람 정답: 모든 방법이 전수 coverage를 가진 뒤 Top 50 합집합과 합집합 밖 결정적 감사 50건을 블라인드 검토한다. 현재 TF-IDF∪dense는 75건이지만 새 전체 방법 결과로 다시 산출한다.
  5. 지표: precision@50, 관련·높음, 고유 관련 발견, 감사 표본 관련, 상대 회수율, 시간·실패율을 함께 본다. 전체 recall은 계산하지 않는다.
  6. 승인: 고정 표본·사람 정답·재현 지표·담당자 승인 전 정책을 활성화하지 않는다.
