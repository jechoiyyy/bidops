# 과거 화면 기준선의 생성기

이 디렉터리는 초기 관리 화면 시안의 생성기·참조 자산이다. 현재 화면 설계는 [RL UI 명세](../../1016_rootlab-redefinition/ui-spec.md), 승인된 테스트 기준선은 [design-snapshots](../../../web/frontend/tests/design-snapshots/README.md)를 따른다.

테스트 기준선의 출처 설명과 화면 스타일 참조가 이 디렉터리를 가리키므로 자산은 보존한다. 현재 설계의 실행 계획이나 재생성 대상은 아니다. 기존 `_shots/`·`_preview/`와 생성기의 문자열·구조가 달라, 생성기를 실행한 결과로 승인된 기준 이미지를 덮어쓰지 않는다.

옛 이행 계획·무드보드는 이미 삭제됐다. 당시 설명·재생성 명령은 `git show b5a61e4:docs/design/mockups/README.md`에서 찾는다. 예시 데이터는 회사 사실·운영 결과가 아니다.
