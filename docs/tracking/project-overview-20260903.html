조달 신호를
사람의 결정으로 연결하는 시스템

BidOps는 나라장터의 발주계획을 조기에 찾고, 사전규격 RFP를 근거와 함께 검토한 뒤, 입찰공고의 변경을 추적해 사람이 최종 Go/No-Go를 내리도록 돕는 사내 의사결정 지원 시스템입니다. 이 문서는 처음 합류한 기획자와 개발자가 전체 구조, 실제 구현선, 남은 작업을 한 번에 파악하도록 만든 스냅숏입니다.

중요: 자동 입찰·발주처 연락·추적 승인·최종 Go/No-Go는 제품 범위가 아니며 사람이 결정합니다.

공식 연결 우선

공식 식별자만 자동 확정합니다. 제목·기관·예산 유사도는 사람이 확인할 후보일 뿐입니다.

실패를 결과로 보존

unknown, null, 부분 성공, 모델/변환 실패를 0이나 비관련으로 바꾸지 않습니다.

모든 판단은 계보를 가짐

06

데이터·상태 설계 원칙

BidOps의 핵심은 모델보다 “무엇을 근거로 누가 결정했는가”를 재구성하는 것입니다.

Relevance

발주계획 후보가 회사 관심 영역과 관련 있는가. C-2 모델 신호와 사람 feedback.

적합성·준비

기존 공고의 적합성 등급과 회사의 참여 준비 상태. 미확인 자격은 unknown.

추적 상태

미선택 / 계속 추적 / 보류 / 종료. 사람이 사유와 함께 선택.

최종 입찰 결정

go / no_go. delta 결과와 exact document fence를 확인한 별도 사람 결정.
