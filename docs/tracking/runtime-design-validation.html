목표 아키텍처와 의존 방향

핵심 설계는 결정적 파이프라인과 모델 판정을 분리하는 것이다. 웹 내부 스케줄러는 실행을 조정하지만 기존 수집·병합·보고 스크립트의 구현을 복제하지 않는다. 모델 호출 결과는 반드시 제한 JSON과 결정적 검증기를 통과한 뒤에만 정본 저장 계층으로 이동한다.

의존 방향

web/backend는 스킬 스크립트를 서브프로세스와 파일 계약으로만 호출한다. 프론트엔드는 REST만 사용하며 DB·서버 파일 경로·스킬 내부를 직접 참조하지 않는다.

정본 경계

원문과 대형 산출물은 파일 보관소, 사용자 리뷰는 DB가 정본이다. 모델 호출기와 오케스트레이터는 둘 다 DB나 원문 보관소에 직접 쓰지 않는다.

외부 전송 경계

기본 모델은 사내 Ollama다. OpenAI는 공고·회차별 외부 전송 승인이 있을 때만 선택하며 로컬 검증 실패가 자동 전송을 유발하지 않는다.

공고 한 건의 판정 런타임 흐름

논리 호출은 관점 5회, 반론 1회, 종합 1회로 총 7회다. 관점 호출은 데이터 의존성이 없어 동시 실행할 수 있지만 단일 Ollama 인스턴스의 기본 동시성은 1이다. 다섯 관점이 모두 끝나기 전에는 반론을 시작하지 않고, 반론이 끝나기 전에는 종합 판정을 시작하지 않는다.

성능 기준선

후보 60건이면 논리 호출은 60 × 7 = 420회다. 입력 3,000·출력 400토큰의 계산 가정은 약 92분이며, 적재·재시도·경합을 포함한 순차 회차는 약 2시간으로 추정한다. 운영 보장값이 아니라 1차 프롬프트로 다시 측정할 값이다.

재시도

타임아웃·잘린 출력은 제한 횟수만 재시도하고, 스키마 위반은 최대 한 번이다. 근거 누락과 반론 상투구 반복은 재시도하지 않는다. 성공한 재시도가 있어도 앞선 실패 스팬을 지우지 않는다.

출력 규칙

grade와 readiness는 별도 축이다. 미확인 자격은 등급 하향 근거가 아니며 unknown을 0·빈 문자열·확정 사실로 치환하지 않는다.

스케줄 실행 상태와 실패 격리

정기 실행은 여섯 상태를 사용한다. 종결 상태를 다시 실행 중으로 되돌리지 않으며, 복구가 필요하면 원래 회차를 덮어쓰지 않는 별도 실행·스냅샷으로 관계를 남긴다.

파일·REST 계약과 구현 경계

구현 시 가장 중요한 연결점은 내부 함수를 공유하는 것이 아니라 버전이 붙은 파일 계약과 REST 모델을 지키는 것이다. 아래 파일들은 생성 주체와 소비 주체가 분리되며, 미확인 값을 암묵적 기본값으로 바꾸지 않는다.

중복 실행 방지

프로세스 간에는 DB의 run_key 유일 제약, 같은 프로세스 안에서는 기존 PipelineService.start 메모리 잠금을 사용한다. 어느 하나만으로 두 경계를 동시에 대체하지 않는다.

트랜잭션 경계

실행권은 예약 행 커밋으로 획득한다. 나중 요청은 새 회차를 만들지 않고 건너뜀으로 남긴다. 모델 호출처럼 긴 작업을 DB 잠금 안에서 수행하는 설계가 아니다.

역추적 키

모든 결과는 run_id, notice_id, 모델·프롬프트·정책 버전을 연결한다. 승계는 judged_in_run과 recorded_in_run을 분리해 새 호출처럼 보이지 않게 한다.

순서구현 단위선행 조건개발 완료 판정
1회차·예약·정책 버전 영속 모델DB 마이그레이션과 불변 식별자 규칙run_key 중복 요청 하나만 실행권을 얻고, 정책 저장은 항상 새 버전을 만든다.

4결정적 검증·병합과 실패 격리decisions v3, failures v1, 기존 병합 스크립트잘못된 한 공고가 나머지 결과를 막지 않고, 검증 실패 데이터가 결과 파일로 새어 들어가지 않는다.
5웹 수명주기 스케줄러와 따라잡기예약 트랜잭션, 기존 PipelineService 잠금재기동 시 누락 날짜를 하루 단위로 오래된 순서부터 만들고 종결 회차를 덮어쓰지 않는다.
6실행·정책 REST와 관리 화면상태·오류 모델, 담당자 식별·감사 이벤트부분 성공과 누락 수가 보이고, 게이트 미달 활성화 요청이 409와 감사 이력을 남긴다.
7계측·품질 게이트·상시 운영고정 표본, 담당자 리뷰, telemetry v1성공·실패·재시도 스팬이 연결되고 필요한 지표가 하나라도 없으면 스위치를 켤 수 없다.
