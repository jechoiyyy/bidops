# 첨부 확보를 기관 링크와 수동 등록의 혼합으로 구성

- 상태: 채택
- 일자: 2026-08-24

## 맥락

일부 공고는 나라장터 API에 첨부가 없고 발주기관 자체 조달시스템에서만 제공한다. 기관별 인증과 화면 구조가 달라 일괄 자동 다운로드는 불안정하다.

## 결정

발주기관 문자열에 맞는 조달시스템 검색 주소를 자동 생성하고 담당자가 파일을 내려받아 등록한다. 나라장터 제공분과 수동 등록분은 출처를 구분한다.

## 대안

기관 사이트를 모두 크롤링하면 자동화율은 높지만 정책·인증·유지보수 위험이 커 기각했다. 첨부 없는 공고를 제외하면 유망 사업의 심층 검토를 놓쳐 기각했다.

## 결과

시스템은 외부 기관 사이트에서 파일을 직접 가져오지 않는다. 수동 첨부만 삭제할 수 있고, 포털 템플릿은 실사용 검증이 필요하다. 완전 무인 첨부 획득은 현재 결정으로 제공할 수 없다.
