# 사전규격 회사 핏은 사업 범위 카드와 로컬 모델로 판정하고, 부합은 추천만 한다

- 상태: 채택 — 2026-11-27 사용자 결정(사업 범위 카드 v1.2·프롬프트 v3.1 채택, "추천(suggest) 먼저, 자동 요청은 관찰 뒤", 포트폴리오 화면 문구를 main에 넣되 참조 표식 유지). 코드는 PS-01. 운영 모드 전환·실제 모델 판정·품질 인수는 이 결정으로 열리지 않는다.
- 일자: 2026-11-27
- 근거: [측정 기록](../../validation-runs/20261127-company-fit-probe/README.md)(22건, 카드 v1.2 + v3.1 exact 17/22, matched 5/5 precision, recall 5/6, 같은 22건에서 카드 답을 만들었으므로 과적합 위험), [PS-01 명세](../../work/groups/PS/features/PS-01-company-fit-card/spec.md), [운영 배포 기록](../../validation-runs/20261127-company-fit-prod-deploy/README.md)(코드만, 모드 꺼짐)
- 관련: ADR-0078(분석 요청은 사람이 연다)·ADR-0081(엔진 live 전송)·ADR-0054(회사 핏 게이트)·ADR-0072(Mac LiteLLM/Ollama)

## 결정

1. **회사 입력은 사람이 검토한 자연어 사업 범위 카드다.** 위키의 실적 제목 나열은 쓰지 않는다. 카드 파일은 저장소 밖에 두고(공개 저장소), 버전과 sha256으로 고정한다. 판정 입력·결과는 카드 lineage로 저장한다.
2. **모델은 기존 개요 용도의 로컬 LiteLLM `local-agent-main`(Qwen) 하나다.** 프롬프트는 측정한 `prespec-company-fit-v3.1`이고 호출 설정·검증기·재시도는 측정과 같다. hosted 모델로 자동 fallback하지 않는다.
3. **모드는 `off|suggest` 둘이다.** env `BIDOPS_PRESPEC_COMPANY_FIT_CARD_MODE`는 배포 상한이고, 실제 모드는 감사되는 `prespec_company_fit_mode` 행(REST `POST /api/pre-specs/company-fit/mode`, CLI `set-company-fit-mode`)이다. 실효는 상한과 최신 행이 모두 `suggest`이고 그 행이 현재 카드·프롬프트에 묶여 있을 때뿐이다. `auto_request`는 422다.
4. **`matched`는 추천 표시만 한다.** 화면은 "회사 사업 범위와 맞는 사업이에요. 추적을 시작하면 상세 분석을 요청할 수 있어요."를 보이고, 분석 요청은 ADR-0078대로 사람의 추적 시작·`분석 요청`에서만 생긴다. 카드 모드가 실효인 동안 회사 핏을 통한 심층 자동 시작은 없다.
5. **화면 표시는 포트폴리오 시안을 따르되 참조 표식은 지우지 않는다.** 판정 이름은 부합/판단 보류/불일치, 분석 화면에 `회사 적합성` 탭을 둔다. 품질 표식(`참조 실행 · 품질 미측정`)과 가져온 Claude 판정의 `Claude 판정 · 참조` 표식은 운영에서 유지한다(CLAUDE.md 강제 게이트). 표식 제거는 포트폴리오 빌드 전용이다.

## 그대로 둔 것

`unknown`·`null`은 불일치가 아니다. 적합성 판정, 추적 선택, 엔진 분석 결과, 최종 Go/No-Go는 서로 대신하지 않는다. 운영 DB로 Claude 판정을 가져오지 않는다.

## 결과와 한계

- 측정은 카드를 만든 22건에서만 했다. 새 회차 측정 전에는 품질 근거로 쓰지 않는다. 제품 경로 재현(T14)은 격리 스택에서 따로 승인받아 돈다.
- 카드 답변(Q1~Q7·Q9~Q11)은 카드 파일에만 있다. 위키로 옮기는 일과 Q8은 남아 있다.
- 자동 요청(`auto_request`)은 관찰 기준(예: matched 30건 이상·2주·precision 80% 이상)을 먼저 합의하고 ADR-0078을 개정해야 연다.
- 포트폴리오를 이 코드로 다시 빌드하면 추천 표시에도 모드 행이 필요하다(env만으로는 켜지지 않는다).
