# 엔진 분석은 사람이 추적을 시작한 사전규격에만 요청된다

- 상태: 채택 — 2026-11-24 사용자 결정("B로 진행해보자", "루트랩 wiki로만 진행"). 구현 전이다. 실제 모델 전송·운영 활성화·품질 인수와는 별개이며 이 결정으로 어느 것도 열리지 않는다.
- 일자: 2026-11-24
- 근거: [개정안](../../work/groups/RL/features/RL-11-live-prespec-engine/track-start-entry.md), [RL-11 최종 흐름 명세](../../work/groups/RL/features/RL-11-live-prespec-engine/spec.md), 2026-11-23 엔진 위임 시험(`docs/validation-runs/20261123-engine-agent-delegation/README.md`, git 이력), 2026-11-24 운영 조회(추적 중인 사전규격 사업 8건, 개요 완료 하루 30~80건, 등록된 회사 0)
- 관련: ADR-0069(사용자 요청 기반 Luna 심층검토)·ADR-0074(분석 엔진 개발 기준선)·ADR-0050(모델 전송 정책)·ADR-0046 결정 6(추적 결정과 분석의 분리)·ADR-0076 결정 13(사전규격 상세의 결정 띠)

## 맥락

개요 검토 뒤 분석 엔진(`bid-deep-engine`)으로 넘어가는 조건이 코드에 없다. 엔진 실행은 요청 API로만 만들어지고 운영에서는 스위치가 꺼져 있다. RL-11 명세는 시스템이 조건(SW=Y 또는 우선 검토, 추적 중이거나 마감 전)에 맞는 공고를 자동으로 승인 대기에 올리도록 설계했다.

세 방식을 비교했다: 완전 수동(A), 사람의 추적 시작에 묶기(B), 개요 완료 뒤 조건부 자동(C). 실제 실행은 한 건에 수 분과 대량의 토큰을 쓰고 원문·회사 자료를 외부 모델로 보내며, 결과 품질은 합격 기록이 없다(RL-05 reject). 개요 완료 물량은 추적 중인 사업의 열 배쯤이다.

## 결정

1. **분석 요청은 사람의 행동에서만 생긴다.** 사전규격 화면에서 추적을 시작하면(단건·일괄) 그 사전규격에 분석 요청을 등록한다. 이미 추적 중인 사전규격은 `분석 요청` 단추로 연다. 적재·등급·개요 완료·cron은 요청을 만들지 않는다.
2. **요청과 전송 승인은 다른 행동이다.** 요청은 아무것도 전송하지 않는다. 외부 전송은 원문이 준비된 뒤 담당자가 동결된 전송 자료를 읽고 공고마다 승인한 것만 나간다. 일괄 승인은 없다.
3. **2026-11-19의 "추적 결정은 추적만 정한다"를 사전규격에 한해 바꾼다.** 추적 시작은 분석 요청을 함께 올린다. 반대 방향은 그대로다: 요청·승인·결과 어느 것도 추적 상태나 최종 Go/No-Go를 바꾸지 않는다.
4. **RL-11의 자동 후보 경로는 구현하지 않는다.** 미추적 공고는 개요까지만 자동이다. 사람이 요청한 공고는 개요 완료·SW사업대상·C-1 등급을 조건으로 보지 않고 원문 준비만 본다.
5. **요청이 열린 사전규격은 첨부 취득·문서 준비 대상이다.**
6. **회사는 루트랩 위키 묶음 하나다.** 엔진 분석은 설정된 회사 자료 묶음(운영 `rootlab`)만 회사 입력으로 쓰고, BidOps 회사 등록과 회사 근거 바인딩을 요구하지 않는다. 분석 요청·승인 API에는 회사 ID가 없고, 엔진 입력은 바인딩 필드를 뺀 v3다. 위키가 바뀌면 이전 결과는 이전 입력 기준이 된다.
7. **추적 API는 바꾸지 않는다.** 요청 등록은 deep_review의 독립 명령이고 사전규격 화면이 추적 저장 뒤 이어서 부른다. 요청 등록이 실패하면 화면에 보이고 추적 저장은 유지한다.

## 그대로 둔 것

건별 전송 승인과 RL 정책 자동 승인의 구분, 호출 상한, 원문 인용과 차단 조건의 결정적 검증, 결과의 품질 표식(`mock_reference`·`unmeasured_reference`), 사람 인수 뒤에만 운영 기본 표시, 추적 선택과 최종 Go/No-Go의 사람 결정.

## 결과와 한계

- 엔진 분석 스위치가 꺼져 있으면 화면과 API는 지금과 같다.
- live 전송 경로 구현, 감독 시운전, 사람 인수가 각각 남아 있다. 회사 등록은 선행 조건이 아니다.
- 여러 회사를 동시에 다루지 않는다. 기존 회사 범위 엔진 API(RL-09, 데모 경로)는 그대로 남는다.
- 조건부 자동 실행(C)은 품질 측정 뒤 다시 검토한다. 첫 후보는 이미 추적 중인 사업의 사전규격이다.
- 추적 저장과 요청 등록이 두 번의 호출이라 그 사이에 끊기면 "추적 중인데 요청 없음" 상태가 된다. 화면이 그 상태를 보이고 `분석 요청`으로 연다.
