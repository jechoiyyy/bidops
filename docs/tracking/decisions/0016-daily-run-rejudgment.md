# 일간 회차와 제한된 재판정

- 상태: 채택
- 일자: 2026-08-25

## 맥락

정기 실행은 매일 그날의 공고 변화를 회차로 남겨야 한다. 이미 판정한 공고를 매번 다시 호출하면 기존 결과의 승계 경계가 흐려지고, 공식 공고의 상태 변화가 있어도 다시 확인하지 않으면 판정이 오래된 상태로 남는다.

## 결정

회차 단위를 일 단위로 전환한다. 이미 판정한 공고는 정정, 재공고, 사전규격의 본공고 전환이 확인된 경우에만 재판정하고, 그 밖에는 기존 판정을 현재 회차로 승계한다. 승계는 신규 판정으로 기록하지 않고 원 판정의 회차와 버전 정보를 보존한다.

## 대안

매 회차 전량 재판정하는 방법은 변경이 없는 공고까지 반복 호출해 실행 비용과 결과 변동을 키우고, 기존 판정의 승계 의미를 없애므로 기각했다.

한 번만 판정하고 담당자 요청이 있을 때만 재판정하는 방법은 정정·재공고·본공고 전환처럼 확인이 필요한 공식 변화를 정기 흐름에서 반영하지 못하므로 기각했다.

## 결과

일간 회차는 수집 시점의 입력과 판정 분기를 고정한다. 재판정 대상은 정해진 생애주기 변화로 제한하고, 그 밖의 검증 가능한 판정은 모델을 다시 호출하지 않고 승계한다. 비교할 수 없는 값은 자동으로 재판정이나 승계로 확정하지 않고 사람 검토 대상으로 남긴다.
