# 회차를 불변 스냅샷으로 보존

- 상태: 채택
- 일자: 2026-08-24

## 맥락

같은 기간의 원문을 새 규칙으로 재분류하면 후보와 판정이 달라진다. 같은 디렉터리를 덮어쓰면 재현성·규칙 변경 효과를 비교할 수 없다.

## 결정

재실행은 새 실행 ID로 저장하고 이전 실행에는 대체 관계만 기록한다. 새 실행이 판정을 갖추기 전에는 완성된 이전 실행을 최신 유효 회차에서 밀어내지 않는다.

## 대안

기간을 회차 ID로 삼아 덮어쓰면 저장은 단순하지만 이력과 피드백 근거가 사라져 기각했다. 최신 결과만 보존하는 방식도 같은 이유로 기각했다.

## 결과

저장량은 실행 수만큼 늘고 회차 선택기에 대체된 실행도 나타난다. 완료 회차의 산출물·정책 참조·판정을 제자리에서 다시 쓰는 것은 불가능하다.
