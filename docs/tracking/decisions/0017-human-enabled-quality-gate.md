# 품질 게이트 통과 후 담당자가 상시 운영을 활성화

- 상태: 채택
- 일자: 2026-08-25

## 맥락

판정 모델을 이식했다고 해서 검증 통과 기준이 충족되는 것은 아니다. 고정 표본에서 재현성·근거 타당성·관점 분할을 측정하고 회차별 변별력을 확인하여, 기준 미달이나 미측정 상태에서 정기 실행을 상시화하지 않는 운영 경계가 필요하다.

## 결정

상시 운영 활성화는 품질 게이트를 통과한 뒤 담당자가 명시적으로 켠다. 게이트는 고정 표본에서 재현성 80% 이상, 담당자 `동의` 70% 이상, `근거 부족` 10% 이하, 관점 분할 40% 이상을 확인하고 유효 판정이 10건 이상인 회차의 변별력이 10% 이상 25% 이하인지 측정한다. 정보 충분성은 별도 합격 수치를 만들지 않고 측정 결과로 남긴다. 필요한 값이 미측정·`계산 불가`·기준 미달이면 통과로 취급하지 않으며, 게이트 통과만으로 스위치나 정책을 자동 활성화하지 않는다.

## 대안

이식 전에 재측정하고 곧바로 착수하는 방법은 실제 이식 후 실행 환경의 품질을 검증한 결과로 볼 수 없으므로 기각했다.

첨부문서 분석까지 붙인 뒤 측정하는 방법은 1차 판정 품질 게이트에 심층 검토 범위를 섞어 측정 대상을 바꾸고, 이번 상시 운영 전환의 품질을 분리해 확인하기 어렵게 하므로 기각했다.

## 결과

품질 게이트의 측정값과 표본·정책·모델 버전을 기록한 뒤 담당자가 활성화 여부를 결정한다. 기준을 충족하지 못하거나 측정할 수 없는 동안에는 상시 운영을 켜지 않고, 보완 측정과 사람 검토를 계속한다.
