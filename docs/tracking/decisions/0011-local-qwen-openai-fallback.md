# Qwen 우선, OpenAI는 검증 실패 후 건별 승인 보조 경로

- 상태: 채택
- 일자: 2026-08-25

## 맥락

사내망 자동화가 목표이며 로컬 `qwen3.8:27b`를 사용할 수 있다. 파일럿은 유용한 분석을 만들었지만 요구사항 계수·분류에서 오류가 있어 결정적 검증이 필요하다. OpenAI는 품질 보조가 가능하지만 자료가 외부로 나간다.

## 결정

1차 다섯 관점과 심층 자격·요구사항·평가·위험 분석은 Qwen을 기본으로 한다. 검증 실패 결과는 사람에게 보내고, OpenAI는 기본 비활성 상태에서 사용자가 해당 공고 또는 회차의 전송 내용을 보고 승인할 때만 호출한다.

## 대안

처음부터 OpenAI를 기본 모델로 쓰면 외부 전송과 비용이 기본 경로가 되어 기각했다. 검증 실패 때 자동 폴백하면 사용자 승인 원칙을 어겨 기각했다. Qwen 자유서술 한 번으로 끝내는 방식은 파일럿 오류 때문에 기각했다.

## 결과

단계별 구조화 호출, 결정적 검증, 사람 검토 큐, 전송 미리보기와 감사 기록이 필요하다. 로컬 모델 실패가 외부 전송 동의로 간주될 수 없고 모델 결과가 최종 참여 결정을 자동 내릴 수 없다.
