# Qwen 우선, OpenAI는 검증 실패 후 건별 승인 보조 경로

- 상태: 대체됨
- 일자: 2026-08-25

## 맥락

사내망 자동화가 목표이며 로컬 `qwen3.8:27b`를 사용할 수 있다. 파일럿은 유용한 분석을 만들었지만 요구사항 계수·분류에서 오류가 있어 결정적 검증이 필요하다. OpenAI는 품질 보조가 가능하지만 자료가 외부로 나간다.

## 결정

당시에는 1차 다섯 관점과 심층 자격·요구사항·평가·위험 분석은 Qwen을 기본으로 하고, 검증 실패 결과에 한해 사용자가 전송 내용을 승인하면 OpenAI 보조 분석을 실행하기로 했다.

## 대안

처음부터 OpenAI를 기본 모델로 쓰면 외부 전송과 비용이 기본 경로가 되어 기각했다. 검증 실패 때 자동 폴백하면 사용자 승인 원칙을 어겨 기각했다. Qwen 자유서술 한 번으로 끝내는 방식은 파일럿 오류 때문에 기각했다.

## 결과

현재 운영 심층 검토는 승인된 사설 OpenAI-compatible vLLM을 사용하며 hosted OpenAI fallback은 두지 않는다. 외부 OpenAI 계열 모델은 발주계획 선별 비교 실험이나 향후 별도 재분석에서 공개 메타데이터와 승인된 회사 역량 요약만 건별 승인해 전송한다. 로컬 모델 실패는 외부 전송 동의가 아니다.
