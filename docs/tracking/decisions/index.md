# 결정 목록 (호환 진입점)

결정 통합 색인은 [docs/ADR.md](../../ADR.md)입니다.

이 파일은 기존 tracking 경로를 참조하는 링크를 위한 호환 진입점이다. 상세 결정 원문은
이 디렉터리의 ADR 파일에 있으며, 새 결정은 상세 ADR을 추가한 뒤 docs/ADR.md 색인을 갱신한다.
이 파일에 별도의 결정 목록을 복제하지 않는다.
