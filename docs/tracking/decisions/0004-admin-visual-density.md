# 관리자 화면 밀도에 맞춘 별도 시각 체계

- 상태: 채택
- 일자: 2026-08-24

## 맥락

참조 디자인은 마케팅 화면의 큰 타이포와 넓은 여백을 전제하지만 BidOps 사용자는 수십 건과 다섯 관점의 근거를 빠르게 비교해야 한다.

## 결정

참조 팔레트와 그림자 없는 원칙은 유지하되 타이포·간격은 고밀도 관리자 화면으로 설계한다. 경고는 제한된 테라코타 색을 사용하고 모든 상태는 문자 라벨을 함께 표시한다.

## 대안

참조 디자인을 그대로 적용하면 한 화면의 비교량이 크게 줄어 기각했다. 완전히 별도 팔레트를 만들면 기존 시각 정체성을 잃어 기각했다.

## 결과

색만으로 등급·경고를 전달할 수 없다. 마케팅용 여백 규칙을 관리자 화면의 절대 규칙으로 적용하는 것은 불가능하며, 화면 변경은 정보 밀도와 접근성을 함께 검증해야 한다.
