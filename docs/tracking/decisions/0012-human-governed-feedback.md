# 피드백은 변경 제안을 만들고 사람이 새 정책을 승인

- 상태: 채택
- 일자: 2026-08-25

## 맥락

지속 사용으로 판정·리포트·UX를 개선하려면 피드백이 기준에 연결되어야 한다. 반면 소수 사례나 잘못된 피드백이 즉시 자동 학습되면 기준이 설명 없이 흔들린다.

## 결정

1차 판정 품질, 심층 리포트 품질, 실제 사업 결과, UX·처리 흐름을 구분해 수집한다. 집계는 변경 제안을 만들고 사람이 승인한 경우에만 새 정책 버전을 활성화한다.

## 대안

피드백으로 프롬프트·가중치를 자동 갱신하면 적응은 빠르지만 재현성과 책임 있는 승인 경계가 무너져 기각했다. 자유 메모만 모으면 개선 효과를 측정하기 어려워 기각했다.

## 결과

피드백 유형·공고·회차·정책 버전·실제 결과를 연결해야 하고 변경 제안/승인 이력이 필요하다. 사용자의 한 번의 수정이나 클릭이 기준을 자동 바꾸는 것은 허용되지 않는다.
