# 리뷰 정본은 DB, YAML은 호환 내보내기

- 상태: 채택
- 일자: 2026-08-24

## 맥락

빈 YAML 양식을 사람이 직접 채우는 방식은 실제 피드백 축적로 이어지지 않았다. 다만 기존 skill과 외부 처리에는 YAML 형식이 남아 있다.

## 결정

리뷰는 화면에서 운영 관계형 DB에 저장하고 공고·회차별 DB 행을 정본으로 삼는다. 현재 운영 DB는 PostgreSQL 17이다. YAML은 초기 가져오기와 `bidops.feedback.v2` 호환 내보내기로 유지한다.

## 대안

YAML만 유지하면 버전 충돌과 빈 피드백 문제가 지속되어 기각했다. YAML을 완전히 없애면 기존 워크플로 호환이 끊겨 기각했다.

## 결과

파일을 손으로 고쳐도 기존 DB 리뷰가 자동 변경되지 않는다. DB와 파일이 다를 때 파일을 정본으로 해석하는 동작은 허용되지 않으며 백업은 DB를 포함해야 한다.
