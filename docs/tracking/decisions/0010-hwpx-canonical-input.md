# HWP는 헤드리스 변환한 HWPX를 분석 정본으로 사용

- 상태: 채택
- 일자: 2026-08-25

## 맥락

파일럿에서 HWP 직접 파싱 결과는 일부 문장·표·요구사항 ID를 잃었고 HWPX 변환본은 더 완전한 구조를 보존했다. 운영 자동화에는 사람의 매번 수동 변환도 맞지 않는다.

## 결정

원본 HWP를 보존하고 헤드리스 변환기로 HWPX를 만든 뒤 그 결과를 분석 정본으로 사용한다. 대표 표본은 한컴 변환 결과와 비교한다. `hwp-rs` 직접 파싱은 운영 입력 경로에 넣지 않는다.

## 대안

HWP 직접 파싱은 변환 단계가 없지만 관찰된 누락 때문에 기각했다. Windows 한컴 자동화를 기본 경로로 쓰면 충실도는 높을 수 있으나 서버 자동화·라이선스·운영 의존성이 커 보조 검증으로 남겼다.

## 결과

변환기 배포·격리·버전 기록과 회귀 문서가 필요하다. 변환 실패 HWP를 직접 모델에 넘기거나 HWPX가 원본과 같다고 검증 없이 가정하는 것은 허용되지 않는다.
