# 판정 기준은 불변 정책 버전을 정본으로 관리

- 상태: 채택
- 일자: 2026-08-25

## 맥락

다섯 관점의 판정 기준과 프롬프트는 실행 결과를 재현하고 회차별 적용 기준을 역추적할 수 있어야 한다. 사용자가 기준을 바꾸더라도 이미 끝난 회차의 정책 참조를 바꾸지 않는 관리 경계가 필요하다.

## 결정

판정 프롬프트와 기준은 정책 저장소의 불변 버전을 정본으로 이관한다. `skills/bidops-screen`의 문서는 Claude로 기준을 시험하기 위한 사본으로 유지하며, 운영 판정은 정책 저장소의 버전과 프롬프트를 참조한다. 기준을 저장할 때는 새 불변 버전을 만들고 이후 회차에만 적용한다.

## 대안

`skills/bidops-screen` 문서를 정본으로 유지하는 방법은 운영 회차가 사용한 기준을 불변 버전으로 고정하고 관리 화면의 정책 변경과 연결하기 어려우므로 기각했다.

판정 문서를 폐기하는 방법은 시험 결과와 운영 기준을 비교하고 프롬프트를 사람이 검토할 수 있는 기준 문서를 잃게 하므로 기각했다.

## 결과

각 판정 결과에는 적용한 정책·모델·프롬프트 버전을 연결해 회차에서 사용한 기준을 역추적한다. 시험용 skills 사본의 변경은 운영 정본을 자동으로 바꾸지 않으며, 정책 변경은 새 버전과 사람의 승인 절차를 거쳐 이후 회차에 반영한다.
