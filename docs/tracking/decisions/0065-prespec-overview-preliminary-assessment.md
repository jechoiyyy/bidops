# ADR-0065: 사전규격 개요와 예비 적합성 판단을 한 실행에서 생성한다

- 상태: 채택 — 제품 구현, 운영 비활성
- 결정일: 2026-09-21
- 관련 문서: [의도](../../0921_prespec-preliminary-assessment/intent.md), [명세](../../0921_prespec-preliminary-assessment/spec.md), [계획](../../0921_prespec-preliminary-assessment/plan.md)

## 배경

사전규격 화면은 개요와 기존 선별 등급을 서로 다른 실행에서 읽었다. 담당자가 실제 계약 과업과 회사의 관심 분야를 한 번에 판단하기 어렵고, 같은 앞부분 원문을 여러 모델 단계가 다시 읽을 여지가 있었다. 동시에 새 화면 판단이 기존 자동 준비·회사 핏·심층 검토의 자격을 몰래 바꾸면 사람 결정과 검증 경계가 섞인다.

## 결정

1. `prespec-overview-policy-v8.json`은 사실 개요와 구조화된 예비 판단을 `overview` 용도 모델의 정상 호출 1회에서 만든다. 모델은 축별 관계와 근거 ID만 내고, 서버가 `우선 검토|검토 권장|관찰 대상|제외`를 계산한다.
2. 관심 축은 AI/데이터, 블록체인/DID, 공공 SI/통합관리이며 우선순위는 같다. 핵심 과업·근거·수행 역할이 부족하면 등급을 만들지 않고 `assessment_status=held`, `assessment_grade=null`로 보존한다.
3. 제외 후보, 수치 관계 모호성, 역할 불명확, 모델의 문맥 불확실성, 검증된 인용과 생성 문장 사이의 부정·조건 표식 차이는 선택 의미검증을 1회 요구한다. 형식 재시도 1회를 포함해 실행당 호출은 최대 3회다. 의미검증의 대상 claim·axis ID와 `not_run|passed|failed`를 별도 저장한다.
4. 사실 개요와 판단 객체를 독립 파싱한다. 판단 객체나 선택 의미검증만 실패하면 결정적으로 검증된 개요는 보존하고 등급만 보류한다. 전체 JSON 손상은 형식 재시도 뒤 안전하게 실패한다.
5. 화면 대표값 `display_assessment`는 사람 정정 → 현재 문서의 새 판정/보류 → 기존 선별 등급 → 판정 없음 순으로 계산한다. 목록·상세·`display_grade` 필터·건수는 같은 batch projection을 쓴다. 기존 `grade`와 effective-grade seam은 자동화 의미를 유지한다.
6. 기존 회사 핏과 자동 심층 시작은 새 run의 `completed`만으로 열리지 않는다. 새 계약은 개요 전체 선택 의미검증이 `passed`이고 검사 범위에 `overview_full`이 있을 때만 종전 소비자에 결과를 제공한다.
7. 같은 공고·같은 현재 문서의 `completed|needs_human_review` 결과는 정책·프로필 변경이나 재관측만으로 자동 재실행하지 않는다. 이미 허용된 자동 run은 모든 입력 binding이 같은 완료 결과만 재사용하고 최초 `reused_from_run_id`를 보존한다. 사람이 범위를 확정한 재실행은 새 run에서 실제 모델 평가를 수행하고 과거 결과를 덮지 않는다.
8. migration `0031_prespec_preliminary_assessment`는 계약·정책·프롬프트·validator·프로필·생성 설정·입력 binding과 판단 결과를 기존 run에 추가한다. 구버전 행은 `contract_version=overview-v1`로 남는다. 원응답은 기존 암호화 저장 경계를 유지한다.

## 호환성과 운영 경계

기본 정책 경로는 계속 v7이다. v8 파일과 reader가 코드에 있어도 migration, 실제 모델 비교, 배포, 정책 경로 변경을 자동으로 수행하지 않는다. v8은 고정 원문과 사람 정답으로 현행 개요·새 등급을 각각 측정하고, 별도 운영 확인을 거친 뒤에만 활성화할 수 있다. `unmeasured_reference`, `mock_reference`, `null` 품질은 활성화 근거가 아니다.

이 결정은 ADR-0054의 단일 run·worker 구조와 ADR-0057의 앞부분 세 섹션 범위를 유지하면서 생성·판단 계약을 확장한다. ADR-0056의 회사 핏 통합은 되살리지 않으며, 새 예비 등급은 회사 핏이나 최종 Go/No-Go를 대체하지 않는다.

## 결과

- 담당자는 개요 기준 등급·근거·출처·시각·품질·선택 의미검증 상태를 함께 본다.
- 정상 경로는 한 번의 모델 호출이며 위험 결과만 두 번째 호출을 쓴다.
- 표시 등급과 자동화 자격이 분리되어 새 판단을 도입해도 기존 자동 실행 조건이 바뀌지 않는다.
- v8 활성화 전에는 0031 migration, 권한, web/analysis-worker의 동일 정책 마운트, 품질 비교와 롤백 절차를 별도로 확인해야 한다.
