# 생성자는 엄격하게, 과거 산출물 적재기는 경고 허용

- 상태: 채택
- 일자: 2026-08-24

## 맥락

현재 계약은 필수 관점과 확인 항목을 요구하지만 실제 과거 산출물에는 비핵심 누락이 있다. 표시 계층까지 전부 거부하면 축적된 판정을 검토할 수 없다.

## 결정

새 산출물 생성자는 계약 위반 시 중단한다. 적재기는 식별자·등급·준비 상태가 없으면 해당 판정을 거부하되 관점·반론·확인 항목 일부 누락은 있는 값만 적재하고 경고한다. 누락값은 만들지 않는다.

## 대안

모든 과거 파일을 거부하면 계약은 단순하지만 데이터가 사라져 기각했다. 기본 관점이나 확인 항목을 자동 생성하면 원문에 없는 판단을 만들기 때문에 기각했다.

## 결과

UI와 지표는 경고 및 계산 불가 상태를 표현해야 한다. 적재 성공을 계약 통과로 간주할 수 없고, 과거 데이터 누락을 조용히 정상화하는 구현은 허용되지 않는다.
