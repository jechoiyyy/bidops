# 정책을 사용자 편집 가능한 불변 버전으로 관리

- 상태: 채택
- 일자: 2026-08-25

## 맥락

현재 추가 하드 필터는 없고 실제 사용 피드백에 따라 후보 조건·가중치·프롬프트를 조정해야 한다. 소스 수정만으로 기준을 바꾸면 담당자가 운영하기 어렵고 과거 결과의 근거도 사라진다.

## 결정

선정·분석 기준은 전용 설정과 관리 화면에서 편집한다. 저장은 새 정책 버전을 만들고 이후 시작하는 회차에만 적용하며 각 회차는 사용 버전을 기록한다.

## 대안

소스 코드 상수는 구현이 빠르지만 사용자 수정과 감사가 어려워 기각했다. 활성 정책을 제자리 수정하면 과거 판정을 재현할 수 없어 기각했다.

## 결과

정책 저장소·활성화 UI·회차 연결·버전 비교가 필요하다. 이미 시작하거나 완료한 회차에 새 정책을 소급 적용하는 것은 허용되지 않는다.
