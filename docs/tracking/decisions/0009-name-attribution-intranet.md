# 초기 작성자 식별은 이름 입력, 파일별 권한 분리는 생략

- 상태: 채택
- 일자: 2026-08-25

## 맥락

목표 환경은 사내망이고 리뷰 작성자 식별은 필요하지만 초기 단계에서 파일별 접근 제한의 가치는 낮다. SSO 정보와 계정 운영 주체도 아직 없다.

## 결정

사용자가 이름을 입력해야 변경·승인 행위를 할 수 있게 하고 이름을 감사 기록에 남긴다. 조회와 파일 접근은 사내망 접속자에게 동일하게 허용한다.

## 대안

즉시 SSO를 도입하면 신뢰성은 높지만 외부 조직 의존성과 구현 범위가 커 기각했다. 고정 환경변수 작성자는 여러 사용자를 구분하지 못해 기각했다.

## 결과

이름은 인증이 아니며 사칭을 막지 못한다. 사용자별 권한, 비밀번호, 파일별 ACL을 이 단계에서 제공할 수 없고 외부망 공개도 허용되지 않는다.
