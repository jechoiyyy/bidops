- 범위: DEMO-01~05의 intent/spec/plan 및 연결 공통 계약. 제품 구현 검증이 아니다.
- 검토자: 서로 분리된 3개 컨텍스트, gpt-5.6-sol/high, 읽기 전용.
- 재검토 입력: [파일별 SHA-256](2026-10-06-inputs.json).
- 최초 검토 후 지적을 합쳐 수정하고 재검토 1회만 요청했다.

최초 검토의 queue 미등록/drafting 지적은 미수용: sdlc-feature §4 독립 검사 이후 §5에서 review 전환·큐 등록을 수행하는 정상 순서다. 제품 구현이 시작됐다는 뜻이 아니다.

## 재검토 결과

세 검토자 모두 잔여 차단이 있다고 판정했다. **독립 검사 미통과**다.

| 범위 | 재검토 잔여 지적 | 반영한 수정 (추가 독립 검사 전) |
|---|---|---|
| 01 | runner/auto_preparation 변경 경로·NULL 회귀 누락 | plan 파일/STEP과 spec T4에 추가 |
| 02 | intent 범위·version 회사 composite FK·실패 CLI nullable 충돌 | intent 범위 정렬, source/profile 복합 FK, 실패 nullable 명시 |
| 03 | SourceUnit 근거/정렬 필드 누락·정책 path limit 위치·표 단절 | 기존 excerpt 필드/순서, chunking 키/hash, 표 연결 |
| 04 | reference mode GET gate 충돌·report 오류 code 오기 | mutation만 gate, 기존 review_not_ready 유지 |
| 05 | verifier provenance 미노출·execution ID 모호·두 폭 중복 저장 | FrozenProvenance GET, review/attempt ID 분리, laptop만 mutation |

위 수정은 완료했지만 독립 재검토를 다시 받지 않았다. sdlc-feature §4의 재검사 1회 제한에 따라 추가 검사 여부는 사용자 결정 대기다. 기능은 blocked로 남기고 실행 큐 등록과 구현 준비 완료 판정은 보류한다. 제품 요구를 삭제하거나 검증을 통과로 변경하지 않는다.

## 후속 상태

사용자의 추가 검토 요청 후 [추가 독립 검토](2026-10-06-additional.md)를 완료했다. 위 미통과 판정은 해당 회차 이력이며 최신 판정은 추가 기록을 따른다.
