# BidOps mission

## 목적과 사용자
㈜루트랩의 기획·사업개발 실무자(5명)가 나라장터를 직접 뒤지지 않아도 루트랩이 수주할 수 있는 공고를 놓치지 않고, 참여 판단과 제안서 작성의 출발점을 에이전트가 만들어 준다.
정본은 [PRD](../../PRD.md) §1~4, [업무 규칙](../../business-rules.md), [ADR-0073](../../tracking/decisions/0073-rootlab-real-company-ax-redefinition.md)이다.
자동 입찰·제출, 발주처 연락, 최종 Go/No-Go, 제안서 제출본은 사람의 책임이다.

## 이번 목표 — RL (2026-10-16)
회사는 실회사 루트랩 하나다. 회사 근거는 [회사소개서 프로필](../../reference/company-profile.md)·[홈페이지 프로필](../../reference/company-homepage-profile.md)·[선호·제약 제안값](../../reference/company-preferences.md)이며 미확인 값은 [인터뷰](../../1016_rootlab-redefinition/company-interview.md)로 채운다.
세 단계 목표를 순서대로 간다.
- G1 발견·알림: 평일 08:00 브리핑(상위 N건·이유·차단 조건·마감)을 Slack bot 전용 채널과 화면으로 보내고 실무자는 채택·무시로만 반응한다. 사전규격·입찰공고가 1순위, 발주계획은 반복 발주처의 연차 사업 예고 전용이다.
- G2 판정 근거: 요구사항 카드(HP-01)·자격·예산·일정을 회사 근거와 대조해 참여 판정 보조(진행 가능·조건부·어려움·판단 불가)·차단 조건·충족/부족/미확인·다음 행동을 원문 쪽까지 보여 준다.
- G3 제안서 초안: 요구사항 대응표와 사업 이해·수행 방안·유사 실적 절을 PDF(1차)·HWP(후속)로 만든다. 과거 제안서·표준 문구는 없으므로(인터뷰 E1·E3) 제안요청서 목차와 회사 근거만으로 생성한다. 입찰 절차·서류는 [bid-procedure](../../1016_rootlab-redefinition/bid-procedure.md)를 따른다.
모든 LLM 작업은 codex-exec `gpt-6-luna`(HP-00 identity)이며 공고·회사 근거 전송은 정책 단위 사전 승인으로 자동화하고 건별 감사는 남긴다. 로컬 LLM 토큰 최적화는 구현 완료 뒤 별도 기능이다.

## 성공 기준
실무자가 직접 서칭을 그만둔다(기준선: 5명 × 2.5일마다 약 60분, 연 약 500시간 추정).
나중에 참여한 공고 중 브리핑에 없던 건이 0이고, 브리핑 상위 N의 채택률을 기록한다.
G2는 사용자가 모델 출력 전에 쓴 gold 10건과 대조해 판정 일치·차단 조건 recall·카드 상태 일치를 측정한다(수치는 RL 기능 spec에서 고정).
G3는 요구사항 누락 0과 실무자의 작성 시간 감소로 판정한다.
확인된 회사 사실, 제안값(`proposed`), 모델 의견, 미확인을 분리하고 참조 실행을 운영 품질로 승격하지 않는다.

## 범위 밖
자동 입찰·제출, 발주처 연락, 최종 Go/No-Go 자동화, 제안서 제출본, 외부 공개·SSO, 그래프 편집 UI, RDF/OWL·SPARQL, 별도 그래프 DB(Neo4j 실험 보류), OCR, 가상회사·다회사 비교, C-2 정책 변경, 입찰 delta worker는 이번 범위에 넣지 않는다.
기존 운영 범위와 생애주기 목표는 폐기하지 않는다.

## 현재와 목표
현재 main에 회사 경계·그래프·회사 화면(DEMO-01~04), 요구사항 카드 inventory(HP-01), Luna identity(HP-00), Luna narrative-v2 심층 경로가 있다.
루트랩 회사 등록, 브리핑·Slack 전송, 사업기회 타임라인, 카드 기반 판정, 제안서 초안, gold 인수는 구현 전이다.

## 이전 목표 — HP (2026-10-14 ~ 2026-10-16, 종료) · DEMO (2026-10-06 ~ 2026-10-14, 종료)
HP는 가상 온웹서비스 1사로 심층 검토를 재정의했고 HP-00·01만 구현·검증됐다. HP-02~06은 2026-10-16에 폐기했다([ADR-0071](../../tracking/decisions/0071-homepage-single-company-deep-review.md)). DEMO는 가상 SI 3사 비교였고 DEMO-05 인수는 중단했다([ADR-0070](../../tracking/decisions/0070-multi-company-knowledge-demo.md)). 두 결과는 품질 근거가 아니라 설계 입력(카드 단위 근거, 단일 모델, 운영 시간 목표)으로만 쓴다.
