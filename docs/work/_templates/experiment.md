# <실험 제목>

- 실험 ID: `<YYYY-MM-DD>-<slug>`
- 관련 기능: `<기능 ID>` 또는 없음
- 상태: 계획 / 실행 중 / 판단 완료

## 가설

한 문장. "A가 B보다 C에서 낫다" 꼴로, 무엇을 비교하고 어느 기준으로 판단할지 드러나게 쓴다.
