# gold 10건 대조 인수 — intent (초안, interview 전)

- 기능 ID: `HP-06-gold-acceptance`
- 상위 항목: [HP 로드맵](../../../../constitution/roadmap.md), [HP 공통 계약](../../../../hp-contract.md) §9
- 크기: M — gold 스키마·채점 스크립트·인수 기록, 실제 실행 10건(건별 승인). 제품 코드 변경은 채점 입력 export 정도.
- 작성일: 2026-10-14 (초안; D7과 문서 10건 선정을 닫은 뒤 spec으로 간다)

## 문제

모델 판정의 품질을 잴 사람 정답이 없다. 참조 실행 표식만으로는 "쓸 만한가"를 말할 수 없다.

## 기대 결과

사용자가 모델 출력 전에 쓴 gold 10건이 저장소에 있고(sha256), HP-03 실행 10건의 판정·차단 조건·충족/부족·카드 상태를 제품 밖 스크립트로 채점한 수치와 불일치 목록이 인수 기록에 남는다.

## 유즈케이스

| 유즈케이스 | 실행 방법(명령·화면·API) | 확인 기준 |
|---|---|---|
| gold 작성·검증 | `docs/hp-gold/<이름>/gold.v1.json` + `scripts/hp-gold-check.py` | 스키마 통과(판정 enum, 차단 조건, 충족 5·부족 5, 주의, 카드 상태 10) |
| 실행 10건 | HP-03 경로, 건별 승인 | 10건 completed 또는 실패 사유 |
| 채점 | `scripts/hp-score.py --gold ... --verdict ...` | 판정 일치 수, 차단 조건 recall, 충족/부족 precision, 카드 상태 일치율, `scoring_input_sha256` |
| 불일치 검토 | 채점 출력의 불일치 목록 | 사용자가 모델 오류/gold 오류/해석 차이로 분류, gold 수정은 새 버전 디렉터리 |
| 인수 기록 | `docs/validation-runs/<날짜>-hp/HP-06/README.md` | 수치·임계값·판단, 참조 표식 유지 |

## 선행·후속 기능

- 선행: HP-04-practitioner-verdict(화면 인수 포함), HP-03 실행.
- 후속: 없음.

## 영향 범위

- 모듈·컴포넌트: `docs/hp-gold/`, `scripts/hp-gold-check.py`, `scripts/hp-score.py`, verdict export(JSON).
- 큰 틀 문서의 절: HP 공통 계약 §9·11(D7), model-quality-gate.md(채점 방식 참조).
- 데이터·저장소: 없음.
- 외부 서비스·호출: HP-03 실행 10건(건별 승인, 약 10×40분).

## 제약

- (공통) feature.json constraints 전체를 따른다(HP-00 intent와 같은 목록).
- (기능별) gold는 모델 출력 전에 쓴다. gold를 고치면 옛 버전을 그대로 두고 새 디렉터리를 만든다. 채점은 제품 밖에서 한다.

## 범위 밖

품질 게이트 활성화·운영 전환, 자동 재채점.
