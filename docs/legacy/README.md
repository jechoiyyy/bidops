# 기존 문서 보관

`planning/`은 웹 관리 화면 구현 전에 작성된 프로젝트 개요·PRD·아키텍처·통합 ADR·구현 계획을 원래 내용과 함께 보존한다. 현재 결정과 구현 규칙은 프로젝트 루트의 작업 지침과 `docs/` 소문자 운영 문서가 기준이며, 보관본의 미래 계획이나 당시 상태가 현재 코드와 다를 수 있다.

`validation/`은 초기 skill 워크플로 검증 기록을 보존한다. 날짜별 실행 증거는 기존 `docs/validation-runs/`에 있으며, 심층 검토 연구는 `docs/deep-review-pilot/`, 회사 근거자료는 `docs/reference/`에 계속 분리한다.
