# 합성 회사 홈페이지 기준 회사 프로필 (예시)

> 합성 회사의 가상 예시다. 실제 회사 자료가 아니다.
> 운영에서는 실제 `company-homepage-profile.md`를 이 자리에 둔다(`docs/operations/setup.md` "웹의 회사자료 입력 전제").
> 정보 상태: `homepage` = 홈페이지 본문에서 확인, `inferred` = 홈페이지 사실에서 도출, `unknown` = 확인 불가

## 1. 기업 개요 (`homepage`)

| 항목 | 값 | 출처 |
|---|---|---|
| 회사명 | 합성 회사 | `/` |
| 주력 분야 | 공공 웹 포털 구축 | `/about` |
| 설립일 | unknown | — |
