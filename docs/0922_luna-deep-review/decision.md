## 채택한 구현 기본값

- Codex 실행 컨테이너는 합성 워커가 호출하는 수동적 실행 경계다. 별도 큐 소비자나
  동시 실행 슬롯을 만들지 않는다. DB·객체 저장소 자격증명은 전달하지 않는다.
- 전송 미리보기와 건별 승인, 입력 동결을 적용한다. 승인된 입력과 동일 실행에서
  검증된 선행 결과만 후속 단계에 전달한다.
- 원문 대조 기본값은 on이며 기존 실행별 off 선택과 보고서 표식을 보존한다.
- 호출당 15분, 검토 전체 2시간, 자동 모델 재호출 없음. 새 불변 정책에 고정한다.
- 새 Luna 정책으로 생성한 결과는 `unmeasured_reference`다. Qwen 자동 fallback은 없다.
- 기존 Qwen 검토를 Luna로 실행할 때 새 정책의 새 검토를 만들고 이전 검토를 보존한다.
- 장애 시 신규 요청을 차단하고 조회·수집·개요검토를 유지한다.

## 기존 규칙과의 충돌 처리

현재 운영 문서·프런트 지침은 hosted 심층검토와 RFP/회사 근거의 외부 전송을
허용하지 않는다. 이번 사용자 요청과 채택 계획은 **사전규격의 사용자 요청 기반
Luna 참조 실행**을 구현하는 예외다. 발주계획 전송 규칙 전체나 Qwen 장애 시 자동
fallback을 허용하는 결정이 아니다.

구현과 함께 ADR·아키텍처·업무 규칙·계약·관련 AGENTS·운영 문서에 같은 예외를
명시한다. 문서 작성만으로 실제 자료 전송을 승인받았다고 기록하지 않는다.
migration, 재배포, 정책 적용, 실제 모델 호출은 저장소 운영 지침에 따라 각각
직전에 사람 확인을 받는다. 확인 요청 전 코드·격리 검증·적용 명령을 준비한다.

## 미채택·후순위

심층검토 자동 시작, 입찰공고 지원, 요청 전용 화면, 일괄 요청, 독립 병렬 워커,
문서 전체 단일 호출로 분석 재설계, 모델 자동 fallback은 이번 구현에 넣지 않는다.
