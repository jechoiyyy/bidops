- 연결: [명세](spec.md) · [구현 계획](plan.md) · [결정](decision.md).

## 목적

MVP 데모에서 실제 사전규격의 심층검토 결과와 웹에서의 확인 방법을 보여준다.
Qwen으로 완성하지 못한 보고서 생성 경로를 사용자 요청 기반
`codex exec` / `gpt-5.6-luna` / `xhigh` 실행으로 연결한다.
Luna의 품질 향상을 이미 검증한 것으로 전제하지 않는다.

## 사용자 흐름

기존 사전규격 목록 → 상세 → 심층검토 요청 → 외부 전송 내용 확인·승인 →
실행 대기·분석 중 → 기존 설명형 보고서와 원문 근거 확인.

수집·문서 준비·개요검토 자동화는 유지한다. 심층검토 자동 시작은 후순위로
미루고 사용자가 요청한 건만 순차 처리한다. 요청 뒤 담당자가 별도 CLI를
매번 실행할 필요는 없다.

## 범위와 성공 기준

- 사전규격부터 지원한다. 입찰공고 확장, 전용 목록, 일괄 요청은 이번 범위 밖이다.
- 기존 문서 분석 → 회사 대조 → 종합의 3단계와 설명형 보고서를 재사용한다.
- 기존 합성 워커의 공용 슬롯 1개를 유지한다. Luna 실행 동안 개요검토가 대기할 수 있다.
- 웹 요청부터 실제 Luna 실행·검증·저장·보고서/근거 조회까지 승인된 표본으로 연결한다.
- 참조 분석의 처리 완료와 품질 검증 완료를 구분한다. `unmeasured_reference`를 유지한다.
- 심층검토 의견, 사업 추적 선택, 최종 Go/No-Go는 사람이 각각 결정한다.

## 선행 작업과 관계

[설명형 심층검토 개선](../0922_deep-review-improvement/intent.md)의 stage/report v2,
문장별 근거, 원문 대조 설정, 보고서 읽기·수정·의견 기능을 기반으로 한다.
진행 중인 작업 트리 변경은 보존한다. 선행 작업의 Qwen 유지 결정은 이번
MVP 신규 심층검토 실행에 한해 Luna 선택으로 대체하며, 기존 Qwen 정책·실행·
보고서 이력이나 수집·개요검토 모델을 소급 변경하지 않는다.
