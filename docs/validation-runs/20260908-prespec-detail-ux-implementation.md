`bidops-prespec-detail-ux-20260908`의 HTML·TSX/CSS·상태별 시안을 직접 적용했다.
기준 시안과 실행 산출물은 저장소 밖 `/home/jechoi/design-previews/`에 보관한다.

## 적용 범위

- 왼쪽 일반 스크롤 본문과 오른쪽 **400px** 결정 패널. 공고 헤더는 고정하지 않고
  결정 패널만 sticky로 유지하며 긴 입력에서도 저장 버튼이 패널 하단에 남는다.
- 제목 20px, 발주기관·공식 사전규격번호 16px/600, 핵심 요약 15px. 번호 복사와
  유효한 수집 URL의 새 탭 열기를 제공한다. 공식 번호 대신 내부 PK를 쓰지 않는다.
- 예산·의견등록 마감 2열 → 권고·품질 표식 → 핵심 요약 → 우선 확인 사항 → 첨부·근거·이력.
  상세 설명과 품질 정보를 접되 검증 실패 경고와 품질 표식은 항상 보인다.
- 오른쪽에 `추적 시작 → 계속 추적`, 사유 드롭다운·기타 직접 입력, 담당자·저장을 배치한다.
  저장 완료 화면의 담당자·사유는 서버 응답을 사용한다. 기존 추적·승계 건은 다시 입력하지 않고
  해당 사업 추적으로 이동한다. 보류·종료는 사업 추적에서 관리한다.
- 기존 공용 저장 로직·미저장 이동 보호·API 오류·원문 위치 검증을 유지한다. 상태 enum,
  수집기·API·DB 계약은 바꾸지 않았다. 담당자 이름은 기존과 같이 감사 표식이다.

## 데이터 경계

현재 사전규격 수집기는 상세 URL을 `null`로 둔다. API가 유효한 절대 HTTP(S) URL을 제공할 때만
원문 버튼을 표시하며, 첨부 URL이나 추측한 나라장터 주소로 채우지 않는다. 실제 확인한 공고
151·570은 URL이 없어 안내 문구가 보인다. URL 새 탭 동작은 가상 원문을 사용해 검증했다.
개요 API에는 개별 확인 항목과 근거의 대응 관계가 없어 일반 근거 목록으로 이동한다.
참조 실행·mock·표식 없음은 운영 품질 통과를 뜻하지 않으며 기존 표식을 유지한다.

## 검증

검증 소스는 직전 반영 frontend를 기준으로 아래 변경 파일만 합쳤다. 작업 트리의 미반영
`PageOverviewSection` import·렌더링은 그대로 두고 배포 사본에서만 제외했다.
기존 backend·API·목록 변경을 이번 반영에 포함하지 않았다.

| 검사 | 결과 |
|---|---|
| `npm run build -- --outDir dist-ux` | TypeScript strict·production build 통과 |
| 작업 트리 TypeScript `--noEmit` | 통과 |
| `npm run test:contrast` | 9 passed |
| `PW_PORT=4193 PW_OUT_DIR=dist-ux npm run test:screens -- --workers=4` | **455 passed, 11 failed, 6 skipped** (4.4분) |
| 새 상세 시나리오 | 위 전체 검사에서 8 passed: 두 폭 배치, 번호 fallback·복사, URL 없음·부적합, 새 탭·저장 실패 |
| 품질 상세 접기 검사 수정 후 집중 재실행 | 1 passed. 품질 표식 상시 표시와 접은 설명을 구분하도록 기대값 변경 |
| 최종 저장 결과 보완 후 집중 검사 | 4 passed: 두 폭 시안 대조·서버 감사값 표시·원문 새 탭/저장 실패 |
| 시각 확인 | 1280×800·1440×900, 정상·긴 제목·문서·이력·미확인·로딩·실패·드롭다운·기타·저장 실패 등 PNG 19개 |
| 실제 API 읽기 | 반영 전·최종 반영 후 각 8개 캡처. 공고 151·570, 두 지원 폭. 가로 넘침 0, 패널 400px, 기관 16px, 공식 번호·헤더 스크롤·하단 저장 확인 |

전체 실패 11개 중 1개는 의도한 품질 상세 접기로 기존 검사가 숨겨진 설명을 찾던 항목이다.
검사를 변경하고 재실행해 통과했다. 나머지 **기존 실패 10개**는 직전
[결정 패널 검증](20260908-prespec-decision-rail.md)과 같다: 공통 상호작용 3개,
회차/경로 맥락 5개, 마감 쿼리 1개, 별도로 작업 중인 미반영 목록 폰트 검사 1개.
전체 화면 게이트 통과로 기록하지 않는다. 픽셀 기준선은 교체하지 않았다.
실제 API 확인에서는 쓰기·모델 실행 없이 GET만 사용했고 브라우저 예외가 없었다.

최종 집중 검사 명령:

```bash
PW_PORT=4193 PW_OUT_DIR=dist-ux npx playwright test --project=app tests/pre-specs.spec.ts \
  -g '사전규격 추적 선택에 성공|수집된 원문 URL|승인 시안 대조'
```
