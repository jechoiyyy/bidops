## 배경

- 지금까지 채택 후보였던 방식은 에이전트가 실적 페이지를 전부 읽고 매번 자기 색인을 새로 만드는 것이었다([기록](../20261123-engine-agent-delegation/README.md)). 위키의 뼈대(목차, 링크, 형식 검사)는 있었지만 "지식을 정리해 두고 갱신한다"는 부분이 없었다.
- 역량 페이지 10개는 합쳐 2만 4천 자이고 6개는 실적 링크가 없었다. "이 업무를 어느 사업의 어느 요구사항에서 했다"는 기록이 위키 어디에도 없었다.

  - 인용 검증: 인용이 인용한 페이지에 글자 그대로 있는 비율.
  - 정답과 같은 페이지: 정답이 든 실적과 에이전트가 든 실적이 겹치는 비율(같은 업무의 근거가 여러 사업에 있으므로 참고값).
