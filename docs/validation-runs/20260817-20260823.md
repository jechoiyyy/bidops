## 실행 범위

- 전국 나라장터 용역 본공고: 수집 완료
- 용역 사전규격: API 활용 권한 미등록으로 수집하지 못함. 재수집 시도에서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 반환됐다
- 판정 기준선: 공고명과 나라장터 목록 API 메타데이터(조달 분류, 지역 제한, 자격 플래그, 생애주기 필드)

| 시점 | 내용 |

2차 개정에서 바뀐 사항은 다음과 같다.

- 판정 파일의 스키마를 계약에 명시하고, 병합 스크립트가 값을 채워 넣던 동작을 제거했다. 이전 실행에서는 40건 가운데 35건에 관점·반론·확인 항목이 없었고 스크립트가 기본값을 주입했으므로, 보고서에 표시된 반론 19건이 서로 같은 문장이었다.
- 지역 제한을 `rgnLmtBidLocplcJdgmBssNm`에서 읽도록 고쳤다. 이전에는 존재하지 않는 필드를 읽어 2,546건 전부가 `null`이었다.
- 조달 분류, 사전규격번호, 재공고·정정 이력, 실적제한경쟁과 기술평가 여부를 정규화 결과에 보존했다.
- 개념 일치 신호에 출처(`field_kind`)를 기록하여, 공고명에서 나온 신호와 조달 분류명에서 나온 신호를 구분했다.
- 감사 표본을 무작위 추출에서 표적 추출로 바꾸었다.
