# A안 설명형 본문 — 웹 시안

2026-09-22. 사용자가 채택한 [A안 본문](../report.md)을 읽는 화면이다. 제목·상태만 표시하던 초기 시안을 교체했다. **가상 데이터이며 실제 Qwen 결과·API·운영 DB와 연결되지 않았다.** Qwen 제품 경로와 수정 필요성은 [호출 경로 점검](../qwen-analysis.md)에 있다.

## 열기

[독립 HTML](index.html)을 브라우저에서 직접 열거나, 실행 중인 로컬 미리보기 `http://localhost:5175/`를 사용한다. HTML에는 코드·스타일·글꼴·가상 본문이 포함되어 외부 네트워크 없이 동작한다. 이 기기의 Orca 공개 Artifact 공유는 비활성 상태로 확인됐으므로 공개 링크를 발행하지 않았다.

## 화면과 조작

- 본문 8개 절과 표 5개를 모두 펼쳐서 읽는다. 왼쪽 목차는 현재 절을 표시하고 해당 절로 이동한다.
- 사용자가 선택한 **편집된 문서형**으로 핵심과 상세를 구분한다. 첫 절에서는 판단 조건을 먼저 강조하고 회사자료·수행·계약의 상세 설명으로 이동한다. 모든 기존 문장은 남겨 두었다.
- 절의 정보 흐름, 소제목 번호, 표의 읽기 안내로 위계를 표현한다. 4절은 문서 조건→회사 영향→확인 사항→판단 갱신의 관계를 먼저 보여 주고 상세 설명을 이어 둔다. 도식의 각 단계에서도 근거를 확인한다. 도식은 가상 자료의 해석이며 실제 분석 결과가 아니다.
- 문장 옆 `근거`를 누르면 오른쪽에서 관련 가상 문서·회사자료를 확인한다. 연결된 자료가 여러 개면 선택하거나 앞뒤로 이동한다. 실제 PDF 뷰어가 아니라 가상 원문 발췌다.
- 패널을 닫거나 Escape를 누르면 본문의 근거 버튼으로 초점이 돌아간다. 패널을 여닫을 때 읽던 문장의 위치를 유지한다.
- `본문 집중`은 탐색 영역을 숨기고, `글자 크게`는 본문·표의 글자 크기를 조절한다. 보고서 내용과 형식은 하나다.
- `본문 내려받기`는 같은 `report.md`를 Markdown으로 내려받는다. 별도의 요약본이나 새 분석을 만들지 않는다.
- 사람 의견은 본문에 미작성 상태로 표시한다. 이번 시안에서 의견 저장·분석 실행·추적 변경을 제공하지 않는다.

## 내용과 빌드

`prototype.jsx`가 `../report.md`·`../report-source.md`를 직접 포함하고 문단·절·표·근거를 표시한다. 보고서 내용을 시안용 짧은 문장으로 별도 복제하지 않는다. 사업 메타데이터와 검토 안내는 같은 가상 자료를 사용한다. 실제 제품에서는 승인된 서버 보고서 계약을 소비해야 하며, 이 Markdown 기반 프로토타입을 제품 분석기로 취급하지 않는다.

저장소 루트에서 `node docs/0922_deep-review-improvement/prototype/build.mjs`로 재생성한다. 설치된 React·Astryx·esbuild와 기존 bidops 테마·로컬 글꼴을 사용한다. 앱 빌드·추가 패키지·모델 호출은 필요 없다.

미리보기를 다시 실행하려면 저장소 루트에서 `python3 -m http.server 5175 --bind 127.0.0.1 --directory docs/0922_deep-review-improvement/prototype`를 실행한다.

## 확인 범위

독립 브라우저의 1280×800·1440×900에서 본문 8개 절·표 5개와 문장·제목·표 셀 133개 단위의 보존을 확인했다. 두 폭 모두 8개 목차 이동, 4단계 관계 도식과 단계별 근거, 문서·회사 근거 선택, 닫기와 키보드 초점 복귀, 패널 가시성, 집중·글자 확대, 내려받은 원본의 동일성 검사를 통과했다. 가로 넘침·누락된 테마 토큰·브라우저 오류는 없었고, HTML 로딩 외 외부 요청도 없었다. 최종 화면을 캡처해 확인했다. 실제 API·문서 뷰어·분석 품질·운영 기능은 이번 시안의 검증 대상이 아니다.
