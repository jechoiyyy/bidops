4. MVP 완료 기준

워크플로우 구동 방식은 아래 경로로 확정합니다.

업로드 → safe → 구조화 → bundle ready → Stage 1 → Stage 2 → Stage 3 → machine revision/validation → evidence 조회 → human full revision/revalidation → final opinion → 새 첨부 → 새 bundle/review → 과거 보존

Mock 통과는 기능 흐름의 기준선입니다. 실제 Qwen의 55개 요구사항 품질 점수와 timeout 동작은 별도 모델 승인 gate로 유지합니다.
