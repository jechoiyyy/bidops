주요 과업과 수행 범위

주장 검증 완료 · 운영 승인 아님전체 근거 PDF 열기 ↗
  1. 1
    현행 공제사업 시스템 현황 분석창작준비금·예술인 산재보험·긴급복지 3개 시스템의 업무 절차, 데이터 구조, 연계 현황을 조사하고 이해관계자 인터뷰를 수행한다.
    제안요청서 p.12 §3.1
  2. 2
    통합관리시스템 목표 모델·정보화 전략 수립기능·데이터·연계 아키텍처를 정의하고 재단 내부 시스템과 외부 기관(국세청·근로복지공단) 연계 방안을 제시한다.
    제안요청서 p.15 §3.2
  3. 3
    3개년 단계별 이행 계획과 소요 예산 산정단계별 구축 범위, 일정, 예산과 사업 발주 방안(분리·통합 발주)을 도출하고 우선순위를 제시한다.
    제안요청서 p.19 §3.3
  4. 4
    데이터 표준화·이관 방안공제사업 데이터 표준(코드·용어)을 정의하고 기존 데이터 정비·이관 절차와 품질 기준을 제시한다.
    제안요청서 p.21 §3.4
