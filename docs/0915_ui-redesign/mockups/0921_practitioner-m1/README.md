# 2026-09-21 실무 화면 고도화 시안 M1 — 공용 UI(수집 회차·페이저·빈 상태·문구)

- 게시본: https://claude.ai/artifact/NqoXnqNDyrnb4bHEK1n6iK (비공개, Version 1). `mockup.html`이 게시본의 원본이다.
- 승인: 2026-09-21 jechoi — "권장하는 방향대로". 결정 1 **A안**(`측정 전용 실행` 표식을 회차 줄에 단일화, 목록 바닥 줄의 회차 모드 문구는 없앤다) ·
  결정 2 **회차는 기존 조건에 더한다**로 통일(실행 상태 화면의 `이 회차 보기` 링크는 `전체` 보기로 연다) · 결정 3 단추 이름 **`목록 기준`**, 다이얼로그 제목 `이 목록의 기준`.
- 함께 승인된 것: 공용 `SourceRunFilter`를 `상세 필터` 안에, 누적 옵션 `모든 수집 회차`, 옵션 `09-19~09-20 수집` + 설명 `생성 시각`(회차 ID 원문 제외),
  상세 필터 단추의 걸린 조건 수, 회차 줄 `회차 보기 · … [모든 회차로]`, 회차 목록 오류는 선택기 안(+회차가 걸려 있으면 회차 줄), 공용 페이저(항상 표시·천 단위),
  공용 `EmptyState`·뼈대 로딩, 빈 값 문구(`예산 미제공`·`추정가격 미제공`·`발주 시기 미제공`), 목록 머리 `{화면 이름} 목록 · N건`, 발주계획 검색칸 이름 일치.
- 표시 데이터는 테스트 fixture 값뿐이고 글꼴은 Pretendard 대신 Noto Sans KR로 대체 표시했다.
- 결정 정본은 ADR-0066, 명세는 `docs/0921_practitioner-screens/spec.md` §2다. 보기 탭 `BM25 탈락`의 새 이름은 이 시안의 승인 범위가 아니다(M3).
