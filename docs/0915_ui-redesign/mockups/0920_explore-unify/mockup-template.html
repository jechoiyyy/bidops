시안 1

/order-plans — 사전규격과 같은 골격으로

목록 머리·선택 툴바·열 머리·행 배치·페이저를 사전규격과 같게 맞춥니다. 상세 영역의 내용과 결정 바는 그대로입니다.

ⓐ 목록 폭 리사이저
ⓓ 회차 선택 위치
ⓒ 목록 글자
ⓐ 리사이저를 없애면 목록 폭을 끌어서 조절하던 기능이 사라집니다.사전규격에는 원래 없고 38% 고정입니다. 유지하려면 두 화면 모두에 넣는 편이 "구조를 같게"라는 취지에 맞지만 범위가 커집니다. 권장은 제거입니다.
  1. 1목록 머리를 한 줄로. 제목+건수, 오른쪽에 기본 보기 설명. 세 줄짜리 범위·정렬 설명은 아래 안내 줄로 내립니다.
  2. 2선택 툴바를 사전규격과 같은 단추 표현으로. 단추는 추적 시작·추적 종료·선택 전체 해제 셋. '전체 선택'은 업무 규칙상 넣지 않습니다.
  3. 3열 머리 추가. 사업명 / 발주기관 · 발주 예정.
  4. 4행 배치를 사전규격과 같게. 체크박스는 왼쪽, 발주 예정 월은 오른쪽 열, 상태 칩은 아래 줄.
  5. 5페이저는 목록 영역 안쪽 바닥. 발주계획의 현재 방식을 공용으로 올려 사전규격에도 같게 적용합니다.
  6. 7회차 선택을 상단 바에서 필터 아래 줄로. 사전규격의 '수집 회차'와 같은 자리·같은 라벨입니다. 실행 상태 표시(부분 성공·진행 중·실행 상세)는 상단 바에 남습니다. 목록 영역이 한 줄(약 40px) 낮아집니다.
  7. 6발주기관 강조 블록은 그대로. 공용 컴포넌트로 올려 사전규격과 공유합니다.
시안 2

/pre-specs — 상세 머리에 발주기관 강조 블록

지금은 기관명이 칩 네 개와 한 줄을 나눠 씁니다. 블록으로 감싸면서 칩을 어디에 둘지 두 안을 준비했습니다. 상세 머리는 발주계획처럼 스크롤해도 위에 붙어 있게 바뀝니다.

  1. 1발주기관을 배경이 있는 블록으로. 발주계획과 같은 값(연한 포인트 배경, 안쪽 여백, 모서리)입니다.
  2. 2칩 네 개의 자리. A안은 사업명 아래 줄, B안은 기관 블록 오른쪽. B안은 1280 폭에서 기관명이 길면 칩이 다음 줄로 내려갑니다.
  3. 3목록 바닥의 건수·페이지 표시는 목록 영역 안쪽에 고정. 로딩 중에도 좌우 분할 골격이 사라지지 않습니다.
전체 상세 화면 /pre-specs/:id 머리
ⓑ 아래 식별 줄의 기관명
ⓑ 전체 상세는 머리 구조가 달라 기관명이 두 번 보일 수 있습니다.그대로 두면 기존 검사를 건드리지 않아 변경이 작습니다. 빼면 화면은 깔끔하지만 검사 두 곳을 함께 고칩니다.
시안 3

선택 툴바와 일괄 추적 종료 창

'선택 항목 검토' 단추 하나를 추적 시작과 추적 종료 둘로 나눕니다. 종료 창은 기존 일괄 추적 시작 창과 같은 순서를 따릅니다. 추적을 아직 정하지 않은 계획만 종료되고, 이미 정한 계획은 미리보기에서 제외 건수로 보입니다.

시안 4

종료한 뒤의 목록

기본 보기(검토 대상)는 추적을 정하지 않은 건만 보여 주므로, 종료한 계획은 바로 목록에서 빠집니다. 지워지는 것이 아니라 추적 필터 '종료'와 사업 추적 화면의 '추적 종료' 구역에서 계속 볼 수 있습니다.
