선택 항목 제외·일괄 추적 창을 한 번 확인으로 통일

발주계획과 사전규격의 목록 선택 도구 선택 항목 제외가 같은 창 구조를 쓰게 하고, 발주계획의 두 번 입력·두 번 확인을 한 번으로 줄입니다. 저장 의미는 그대로입니다 — 발주계획은 추적 종료, 사전규격은 검토 제외(목록에서 숨김·복원 가능). 추적 결정 줄의 사유 지우기와 이동 경고 조건도 함께 고칩니다.

  1. 1발주계획 일괄 창 한 번 확인
    창을 열면 대상 건수를 자동으로 확인하고, 담당자·사유를 한 번만 입력한 뒤 단추 하나로 저장합니다. 일괄 추적 시작도 같습니다.
  2. 2사전규격 제외 창을 같은 구조로
    제목·요약 줄·사유·담당자·안내·단추 배치를 발주계획과 같게. 문구만 “검토 제외”.
  3. 3사전규격 제외 오류 수정
    API 호출에 JSON 형식 헤더가 빠져 서버가 422로 거부하던 결함. 화면 변화 없음.
  4. 4사유는 선택지 + 기타 직접 입력
    추적 시작 결정과 같은 드롭다운. 기타 · 직접 입력일 때만 입력칸이 열립니다.
  5. 5담당자 이름만 있으면 이동 경고 없음
    사전규격 목록에서 다음 공고로 넘어갈 때, 사유를 골랐을 때만 기존 안내가 뜹니다.
  6. 6고른 사유를 다시 비우기
    사유 드롭다운에 × 지우기 단추. 누르면 빈 상태(placeholder)로 돌아갑니다.
