- 원칙: 이 화면들의 식별자·해시·실행 정보는 운영 화면에 받을 자리가 없으므로 지우지 않고 같은 화면의 접힌 `기술 정보`로 모은다. 식별자·해시는 전문.
- R4(사전규격): 회사 적합성 실행 정보·주장 ID·개요 실행 정보를 ⑥의 접힌 곳 하나로(실패·사람 확인이면 기본 펼침), 제목 `현재 개요 검토`, `표시 범위` 다이얼로그의 응답 필드 이름을 사람 말로.
- R5(심층 검토): `안전한 오류 코드` → 사람 말 한 문장 + 접힌 기술 정보(모르는 코드는 그대로), 근거 ID·문서 버전·SHA-256·block_key·bbox·정책/프로필 버전 접기, 근거 신뢰도·품질 표식·범위 주석·검증 요약은 밖에.
- R6(Go/No-Go·입찰 변경·셸): 영문 병기 삭제, "비교 프로그램 없음" 안내 1회, `n번째 결정`, 고정 입력 13줄 접기, 사이드바 `관리자 화면` 삭제, `판정 기준` 팝오버의 run_id → 회차 라벨, 공고 정정 다이얼로그의 회차 원문 → 회차 라벨.
